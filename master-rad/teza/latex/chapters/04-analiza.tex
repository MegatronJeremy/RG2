\section{Metodologija}
\label{sec:metodologija}

\paragraph{Hardver i scena.} All timings are taken on a single GPU, an AMD Radeon RX 7900 XTX (RDNA3,
\texttt{gfx1100}); the driver version and operating system are recorded with each result set. The
test scene is Sponza, a standard interior with strong indirect bounce, lit by ten lights (three spot,
six point, one directional) at a fixed render resolution stated with the results. A code-generated
stress scene (a grid of meshes) is available for scaling tests.

\paragraph{Controls for fair comparison.} Several controls keep the measurements honest and
reproducible. The camera is held static for every A/B comparison: a moving camera desynchronizes the
frame sequence between two runs and fabricates differences that are timing artifacts rather than real
effects. The shader cache is cleared before any GPU metric is trusted, since a stale cache produces
nondeterministic results. Performance baselines are per-machine and per-resolution, because absolute
milliseconds are not comparable across GPUs or output sizes. Persisted console variables are ignored
during a benchmark run so that a leftover setting cannot silently change the configuration.

\paragraph{Performance measurement.} Each render-graph pass is wrapped in a GPU timestamp scope, and
a harness (\texttt{perf-bench}) averages those per-pass timings over a fixed frame budget after a
fifteen-frame warmup that also covers the one-frame timestamp latency. The benchmark sweeps a fixed
matrix of configurations, \texttt{rt-off} $\rightarrow$ \texttt{shadows} $\rightarrow$ \texttt{+ao}
$\rightarrow$ \texttt{+refl} $\rightarrow$ \texttt{+gi}, enabling one more effect at each step, so the
cost of an effect is the difference between adjacent configurations. One caveat applies to that
difference: it equals the Forward-pass delta only for shadows and reflections, which are inline in
the Forward pass. Global illumination and ambient occlusion run as their own half-resolution passes
with separate timestamp scopes, so their cost is read from those per-pass scopes plus the total GPU
time, not from the Forward delta alone.

\paragraph{Quality measurement.} Reconstruction quality is measured in-engine by a metrics pass that
computes PSNR and SSIM on the GPU against a ground-truth image. The ground truth is a second,
unjittered, full-resolution forward render of the same frame, optionally supersampled
(\texttt{render.gt.ssaa}) and box-downsampled in linear HDR to give an anti-aliased reference. A
second caveat applies here: the ground-truth path forces raster shadows, so with ray-traced shadows
enabled the metric compares ray-traced against raster shadows, not against a ray-traced reference.
Shadow-quality numbers are therefore either measured on the non-shadow effects against the reference,
or reported with this caveat stated explicitly.
